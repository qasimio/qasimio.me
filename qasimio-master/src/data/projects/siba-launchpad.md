## The problem

A university project can be perfectly usable and still disappear the week after grading.

The repository exists. The demo exists. Maybe a few friends saw it. Then everyone moves on.

The harder part is social. People often wait until the work feels perfect before showing it, which means a lot of work never gets shown at all.

## What I built around it

Launchpad is a public home for student projects, with a website and a GitHub organization around it. The community side is deliberately focused on showing the work rather than becoming another general chat group.

GitHub data is part of the product experience because the user should not have to retype information GitHub already has.

## The difficult part

The difficult part was never the website.

It was getting someone to press publish before they felt ready.

That has changed how I think about products. Sometimes the interface is the easy part of the problem.
