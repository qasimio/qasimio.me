Finding a class at SIBA meant opening timetable pages and looking for the course, section, or room manually.

Nothing was technically broken. It was just annoying.

So Abdul and I built SlotFinder: timetable PDF in, searchable answer out.

I like projects like this because there is no grand idea to defend. The problem is right there. Fix it and see if somebody uses it.
