# Launch checklist

1. `pnpm install`
2. `pnpm run check`
3. `pnpm run format`
4. `pnpm run build`
5. `pnpm dev`
6. Review Home / Work / Journal / About / Contact in dark and light modes.
7. Connect the GitHub repo to Vercel.
8. Verify the preview deployment before touching DNS.
9. Add `qasimio.me` in Vercel and follow the exact DNS record Vercel provides.
10. Verify HTTPS, sitemap, robots.txt, RSS, resume, and OpenGraph metadata.
