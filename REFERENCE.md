# Reference

This version intentionally follows the structure, interaction patterns, motion language, and visual system of Brittany Chiang's v4 personal website:

- https://v4.brittanychiang.com/
- https://github.com/bchiang7/v4

The v4 repository is MIT licensed and its README explicitly permits forks with attribution.

This project is an independent Astro implementation using Qasim Sethar's own content, links, identity assets, and information architecture. The original v4 Calibre/SF Mono font files are not redistributed.
