# World-class review / v4

## Judge A — Creative director

The previous build had competent layout but still read as a portfolio system. Too many boxes, too much uniformity, too much small metadata, and not enough moments where the eye had somewhere obvious to land. The fix is not more decoration. It is stronger composition: fewer repeated patterns, larger type where it matters, full-bleed color used as punctuation, better image treatment, and motion that carries continuity between pages.

## Judge B — Founder / hiring / investment lens

The previous copy over-explained identity instead of proving it. A technical title is easy to claim. Shipped software, users, community work, and a visible trail of decisions are harder to fake. The site should therefore lead with evidence, keep claims specific, and show that Qasim does more than code without turning into a résumé.

## Non-negotiables

- No fake social network.
- No badge wall or skill percentages.
- No vague AI language.
- No invented metrics.
- No visual effect without a reason.
- Strong light and dark themes.
- Multi-page architecture.
- Every serious project gets a real story.
- Notes remain short and owned; X remains distribution.
- Accessibility and reduced motion are first-class constraints.

## Long-term test

The site should become more valuable as Qasim ships more things. Adding the next project or note should be a content operation, not a redesign. The visual system should still make sense if the work later includes products, companies, open source, communities, or work outside software.
