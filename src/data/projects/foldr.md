## Why I built it

I got tired of doing the same file cleanup work over and over.

## What I built

FOLDR maps file types into logical categories, previews the operations before touching the filesystem, watches folders in the background, protects sensitive paths, and keeps an undo history.

## The hard part

File automation is useful only while it is reversible enough to trust. The undo system and preview flow became as important as the organizer itself.

## What happened

FOLDR crossed 100 GitHub stars and 7,300+ downloads according to the project metrics I track. Those numbers include CI/CD activity in the download count source, so the distinction matters.
