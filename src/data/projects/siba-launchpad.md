Launchpad exists because too many student projects disappear the moment grading ends.

The work here is less about software architecture and more about creating the conditions for people to ship: showcasing projects, helping people find collaborators, reviewing work, and building a public trail around things that would otherwise stay inside a course folder.

I also used the GitHub API to pull user information and enable direct starring workflows inside the platform.
