I have used Arch as my daily development environment for roughly two years now.

I use VS Code with Vim keybindings, shell shortcuts, and keyboard-first workflows because moving my hand to the mouse every five seconds gets old.

It is not a productivity religion. I just like staying close to the tools I use all day.
